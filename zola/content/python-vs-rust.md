# Python 與 Rust：何時該選哪一個？

兩者都是優秀的語言，但設計哲學截然不同。

## 快速比較

| 面向 | Python | Rust |
|------|--------|------|
| 開發速度 | 極快 | 較慢（編譯期檢查嚴格） |
| 執行效能 | 較慢 | 接近 C/C++ |
| 記憶體安全 | GC 管理 | 編譯期保證 |
| 學習曲線 | 平緩 | 陡峭（Ownership） |
| 生態系 | 資料科學、AI 最強 | 系統、CLI、Wasm 強 |

## 建議選擇

- **快速原型、資料分析、機器學習** → Python
- **高效能服務、系統工具、需要長期維護的後端** → Rust
- **兩者結合**：用 Python 寫邏輯，關鍵路徑用 Rust（PyO3）加速

實際專案中，很多團隊會同時使用兩種語言，發揮各自優勢。
